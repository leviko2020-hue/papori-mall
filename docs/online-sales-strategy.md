# PAPORI 온라인 영업·판매 전략 (2026-09 기준)

## 0. 현재 상황 진단

| 항목 | 현황 | 문제점 |
|---|---|---|
| 매출 구조 | 한전 직접 90% + 한전 협력업체 10% (전부 오프라인) | 고객 1곳 의존 → 한전 예산/담당자 변경 시 매출 급변 리스크 |
| 주력 상품 | 열화상카메라(HIKMICRO 등 유통), 체결형 케이블 바인더(자체 개발) | 자체 개발품이 쇼핑몰에서 잘 안 보임 (한전 보수자재 카테고리 안에 묻혀 있음) |
| 파포리몰 | 정적 사이트 + Firebase, 상품 페이지 약 490개, `papori-mall.vercel.app` | 자체 도메인 없음, 메타설명·OG태그·네이버 사이트 인증 없음 → 검색 유입이 거의 불가능한 구조 |

**결론: 파포리몰은 "주문 받는 쇼핑몰"보다 "공공기관·협력업체 영업용 온라인 카탈로그 + 견적요청 창구"로 쓰는 것이 맞습니다.**
공공기관 구매 담당자는 일반 쇼핑몰에서 카드결제로 사지 않습니다. 이들은 ① 나라장터(조달청) ② 기관 자체 전자구매 시스템 ③ 견적서 → 수의계약 으로 삽니다.
따라서 온라인 전략은 채널을 3개로 나눠야 합니다.

```
[공공기관]  나라장터 종합쇼핑몰 / 혁신제품 / 우수조달   ← 매출 규모가 가장 큼
[협력업체·B2B]  파포리몰(카탈로그+견적) + 네이버 스마트스토어   ← 한전 협력업체 수천 곳
[일반 기술자·개인]  네이버 스마트스토어 / 쿠팡   ← 열화상카메라·계측기·수공구
```

## 1. 공공기관 온라인 판로 (가장 우선)

### 1-1. 나라장터(조달청) 물품 등록 → 종합쇼핑몰 입점
- 조달업체 등록 → 물품목록번호(식별번호) 부여 → 다수공급자계약(MAS) 또는 일반단가계약 → 종합쇼핑몰 등재
- 등재되면 한전뿐 아니라 **서울교통공사·부산교통공사·지역난방공사·수자원공사·가스공사·지자체**가 입찰 없이 쇼핑몰에서 바로 구매 가능
- 지하철공사·지역난방공사 실적이 끊긴 이유가 "담당자 변경 + 오프라인 방문 중단"이라면, 종합쇼핑몰 등재가 가장 싸게 다시 연결하는 방법

### 1-2. 체결형 케이블 바인더 → 혁신제품 / 성능인증 / 우수조달물품
자체 개발·특허가 있다면 이것이 **가장 큰 기회**입니다.
- **혁신제품 지정**(조달청·중기부): 지정되면 공공기관이 **수의계약**으로 구매 가능, 시범구매 사업으로 기관이 비용 부담 없이 써봄
  - 요건(중기부 기술마켓 트랙): 중소기업 + 나라장터 물품 등록 + 특허/실용신안 보유
- **성능인증(EPC, 중기부)** → 공공기관 우선구매 대상
- **우수조달물품 지정** → 종합쇼핑몰 우선 노출
- 실적 증빙: "한전 납품 실적"을 그대로 다른 공기업 영업자료로 사용 (전력구 → 지하철 전력설비 → 지역난방 열배관 전력선 등 적용처 확장)

### 1-3. 연구개발(R&D) 의뢰 → 제품화 루프
- 받은 R&D 의뢰 중 다른 기관에도 필요한 것을 자체 제품으로 만들어 혁신제품 신청 → R&D가 곧 신제품 파이프라인이 되도록 구조화
- 중기부 "구매조건부 신제품개발사업": 공공기관이 구매를 약속하고 개발비를 지원 → 한전·지하철공사를 수요처로 신청

## 2. 파포리몰 개선 (B2B 카탈로그로)

1. **자체 도메인 연결** (예: papori.co.kr) — vercel.app 주소는 신뢰도·검색 모두 불리
2. **네이버 서치어드바이저 / 구글 서치콘솔 등록** — 사이트 소유확인 메타태그, sitemap.xml 제출 (sitemap은 이미 있음)
3. **모든 페이지에 `<meta name="description">` + OG 태그 추가** — 카톡/문자로 링크 공유 시 미리보기 이미지·설명이 뜸
4. **체결형 케이블 바인더 전용 랜딩페이지** — 메인 상단 배너, 시공 전/후 사진, 시험성적서, 한전 납품실적, 특허번호, 동영상
5. **"공공기관 구매 안내" 페이지** — 나라장터 물품번호, 견적서·사업자등록증·납품실적 PDF 즉시 다운로드
6. **견적요청 → 문자/이메일 즉시 알림** (functions 폴더에 이미 구현되어 있으니 배포만 하면 됨: `functions/README-DEPLOY.md`)
7. **한전 협력업체 대상 DM** — 전기공사협회 회원사 대상 이메일/문자로 파포리몰 링크 발송 (협력업체는 카드·계좌이체 구매가 가능하므로 실제 주문 채널로 작동)

## 3. 네이버 스마트스토어

### 3-1. 입점 방법
1. sell.smartstore.naver.com → 사업자 판매자 가입 (사업자등록증, 통신판매업 신고증, 대표자 인증, 정산계좌)
2. 상품 등록: 카테고리 → 상품명 → 가격/재고 → 옵션 → 이미지(대표 1000×1000 이상) → 상세페이지 → 상품정보제공고시 → 배송/반품
3. **대량 등록**: 스마트스토어센터 "상품 일괄등록(엑셀)" 사용 — 이미 `PAPORI_전체카탈로그.xlsx`가 있으므로 이를 네이버 양식으로 변환하면 수백 개를 한 번에 올릴 수 있음
4. **자동화**: 네이버 커머스API(apicenter.commerce.naver.com)로 상품등록·재고·주문 조회를 프로그램으로 처리 가능

### 3-2. 상단 노출 방법 (적합도 · 인기도 · 신뢰도)
| 요소 | 할 일 |
|---|---|
| **적합도** | 상품명 = `브랜드 + 모델명 + 핵심키워드 + 규격` (예: `HIKMICRO G41 열화상카메라 640x480 산업용 전기설비점검`). 50자 이내, 키워드 반복·특수문자 금지. 카테고리를 정확히, 브랜드/제조사/모델명 필드 반드시 입력, 속성·태그 모두 채우기 |
| **가격비교(카탈로그) 매칭** | 열화상카메라처럼 모델명이 있는 상품은 네이버 가격비교 카탈로그에 매칭 → 최저가 경쟁이 불리하면 "세트 구성(교정성적서 + 교육 + 케이스)"으로 차별화 |
| **인기도** | 클릭·판매·리뷰·찜이 쌓여야 함 → 기존 한전 협력업체 고객에게 스마트스토어로 주문 유도 + 리뷰 요청 (가짜 리뷰·구매는 절대 금지, 적발 시 노출 제재) |
| **신뢰도** | 빠른 배송(오늘출발), 문의 응답 속도, 굿서비스 점수, 판매자 등급 |
| **옵션 구조화** | 2026년 AI 검색 개편 이후 옵션명을 규격·수량 단위로 깔끔하게 작성하는 것이 중요 |
| **광고** | 초기에는 쇼핑검색광고로 롱테일 키워드(`열화상카메라 전기점검`, `케이블타이 대체 바인더` 등)에 소액 입찰 → 판매 누적 후 자연 노출로 전환 |
| **콘텐츠** | 네이버 블로그/카페에 현장 점검 사례(열화상으로 접속부 과열 발견 등) 게시 → 스토어 링크. B2B 제품은 검색량이 적어 콘텐츠 유입 비중이 큼 |

### 3-3. 스마트스토어에 먼저 올릴 상품
- **열화상카메라** (HIKMICRO 전 라인업) — 개인 기술자·설비업체 수요 큼
- **계측기·수공구** — 모델명 검색 수요 있음
- **체결형 케이블 바인더** — 검색 수요는 작지만 독점 상품이라 "케이블 정리", "케이블 결속" 키워드로 1위 가능
- 한전 전용 자재(규격품)는 일반 소비자 수요가 없으므로 스마트스토어보다 파포리몰·나라장터에 둠

## 4. 밤새 작업을 돌리는 방법 (서버 자동화)

| 방법 | 용도 | 비용 |
|---|---|---|
| **Claude Code 루틴(예약 실행)** | 매일 새벽 정해진 시간에 클라우드 세션이 자동 실행 → 상품 상세페이지 작성, 카탈로그 엑셀 → 네이버 업로드 양식 변환, 경쟁사 가격 조사, 블로그 원고 작성 후 저장소에 커밋 | Claude 요금제 내 |
| **Claude Code 웹(클라우드 세션)** | 지금처럼 작업을 맡겨두고 PC를 꺼도 서버에서 계속 진행 | Claude 요금제 내 |
| **GitHub Actions (cron)** | 매일 sitemap 자동 갱신, 이미지 최적화, 링크 점검 | 무료 한도 내 |
| **Firebase Cloud Functions (스케줄)** | 견적요청 알림, 네이버 커머스API로 주문·재고 동기화 | 사용량 적으면 거의 무료 (Blaze 요금제 필요) |

(네이버 판매자 계정 로그인이 필요한 최종 업로드는 사람이 하거나, 커머스API 키를 발급받아 서버에 등록해야 자동화 가능)

## 5. KC인증 없이 수입 판매 가능한 상품 후보

### 원칙
- **전기로 작동하는 제품(배터리 포함)은 거의 모두 KC 대상**입니다.
  - 전기용품 안전(전안법) 또는 **전파법 적합성평가(KC 전자파)** — 열화상카메라·디지털 계측기도 전파법 적합성평가가 필요합니다 (현재 HIKMICRO 제품은 수입원이 받은 인증번호를 확인해 두세요).
- **안전모·안전화·절연장갑 등 보호구는 산업안전보건법상 안전인증(KCs)** 대상 → 제외
- 따라서 KC가 필요 없는 것은 **"전기가 들어가지 않는 기계식·자재류"** 입니다.

| 8~12주 | KC 비대상 수입품 3~5개 샘플 수입 → 협력업체에 테스트 판매 → 반응 좋은 품목만 스마트스토어 확대 |
| 상시 | Claude Code 루틴으로 매일 밤 상품 상세페이지·블로그 원고·업로드 엑셀 자동 생성 |
